# Third-party notices and release gate

The JavaScript dependencies are installed from the exact versions recorded in `package-lock.json`; their individual licenses are listed by npm metadata in that lock/dependency tree.

## byze-miner / byze-rxhash

The P2Pool native miner is derived from the upstream `powhermes/byze-miner` source at commit:

`d84db8a84ba4a06432fcdddbf1584b89a7e52379`

This project intentionally does **not** ship a derived `byze-p2pool-miner` binary in this source release candidate. Before a public binary release, the upstream redistribution/license terms must be confirmed and the release owner must choose a license for this CLI itself.

Developer builds are local builds from the pinned upstream commit and are not evidence that public redistribution rights have been granted.
